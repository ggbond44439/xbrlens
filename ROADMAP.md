# Functional Roadmap

1. Foundation: limits, errors, QName and namespace resolution.
2. Bounded XML parser with namespace expansion and structural guards.
3. XBRL instance model: facts, contexts, periods and units.
4. Exact decimal arithmetic and normalization.
5. Taxonomy schema parser: concepts, role types and imports.
6. Offline taxonomy resolver and catalog support.
7. Label and presentation linkbase support.
8. Calculation linkbase model and graph extraction.
9. Weighted calculation validation.
10. XBRL Dimensions 1.0 explicit members and typed dimensions.
11. Fact integrity and duplicate/conflict diagnostics.
12. JSON and CSV normalization exporters.
13. CLI workflows for inspect, facts, validate, calc and diff.
14. Security hardening and adversarial input tests.
15. Real filing fixtures, differential checks, benchmarks and cross-target verification.
16. Documentation, examples, CI and Mooncakes release preparation.
